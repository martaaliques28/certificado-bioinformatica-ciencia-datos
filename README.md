# certificado-bioinformatica-ciencia-datos
Repositorio de prácticas y actividades de la asignatura Fundamentos Computacionales en Biociencias. En él se recopilan los ejercicios realizados durante el curso para aprender los fundamentos de Unix/Linux, Manejo de archivos y comandos Unix, y análisis de datos biológicos y secuencias de ADN mediante herramientas básicas de bioinformática.
